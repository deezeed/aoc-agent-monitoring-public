# Cedar Cloud -- website + pricing page, copied 14 Oct

Cedar is the cheapest option we found: 12 EUR per TB per month (annual
commitment). They advertise a 99.99 % uptime SLA, the best of the three.

Data location: Cedar's storage regions are Virginia and Oregon. An EU region
is "on the roadmap for next year", with no date. Their DPA allows transfers
under standard contractual clauses only.
