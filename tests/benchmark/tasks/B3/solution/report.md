# Off-site backup storage

## Summary

We compared three providers against two hard requirements: EU data residency
and an uptime SLA of at least 99.9 %. Cedar Cloud is the cheapest but stores
data only in the US. Alder Storage keeps data in the EU but guarantees only
99.5 %. Birchvault meets both requirements and is therefore the pick.

## Comparison

| Provider | Price per TB / month | EU data residency | SLA |
|---|---|---|---|
| Alder Storage | 18 EUR | yes | 99.5 % |
| Birchvault | 21 EUR | yes | 99.95 % |
| Cedar Cloud | 12 EUR | no (US only) | 99.99 % |

## Recommendation

Birchvault: the only provider that meets both hard requirements (EU clause,
99.95 % SLA). Alder Storage is cheaper but its written SLA is 99.5 %, below
our 99.9 %. Cedar Cloud is the cheapest but keeps data in the US.
