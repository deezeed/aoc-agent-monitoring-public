How licensing works

One codebase, license-key-gated — there's no separate Pro build. A Pro key is AOC-PRO-<payload>.<signature>, Ed25519-signed and verified fully offline against a public key embedded in monitor.py. Activating one never phones home. Paste it into Settings → LICENSE once you have it.
