What's on the board

See it, stop it, account for it

  • Live

    Every running session as a bay, every subagent as a strip: current task, progress, time, tokens and cost as they happen.

  • Act

    Native toasts when a session waits on you or an agent stalls. Embedded terminal and Force Stop from the same screen.

  • History

    Every past session with its agents, files changed and spend — searchable, kept locally.

  • Analytics

    Spend by day, project, model and subagent type; file hotspots and hook reliability.

How licensing works

One codebase, license-key-gated — there's no separate Pro build. A Pro key is AOC-PRO-<payload>.<signature>, Ed25519-signed and verified fully offline against a public key embedded in monitor.py. Activating one never phones home. Paste it into Settings → LICENSE once you have it.

Quick start (Free tier)

Installer: download AOC-Setup-<version>.exe from the latest release and run it. It installs per-user (no admin), bundles its own Python, wires up the Claude Code hook and opens the dashboard. The installer isn't code-signed yet, so Windows SmartScreen may warn: choose More info → Run anyway. When a new version is out, the dashboard shows an UPDATE badge that links to it.

From source (needs Python 3.9+; updates via git pull):

git clone https://github.com/deezeed/aoc-agent-monitoring-public.git
cd aoc-agent-monitoring-public
python setup.py

See the README for full setup, architecture, and the two-tier watchdog. Full terms in LICENSE.md.
